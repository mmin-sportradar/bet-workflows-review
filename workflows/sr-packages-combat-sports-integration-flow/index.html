LMT Combat BET Integration

New-client setup for the Combat Package

Responsibilities:
Combat Package: activate regular LMT for MMA only. Premium and Compact versions are not available for Combat.
SPORTRADAR
3 September 2026

BET INTEGRATION TEAM

Confirm the request and activation scope

  1. The Salesforce request goes to the CS team and contains the Combat Package products.
  2. CS clones the ticket for LMT activation and assigns the cloned ticket to the BETI team.
  3. Confirm the request is for the Combat Package.
  4. Activate regular LMT for MMA through the standard licence-activation process for IMG-related products.

Activation scope

Activate LMT only. Do not activate Premium or Compact: neither is available for Combat.

SALES / BET INTEGRATION

Confirm new-client details

Add a comment to the Jira ticket and ask Sales to confirm the following before client-facing setup:

  1. Whether the client wants UFC streaming enabled. Streaming is available only for the UFC league.
  2. The region or regions for streaming, if it is requested.
  3. The client integration point of contact (POC).

BET INTEGRATION TEAM

Find or create the IMGA operator name

The IMGA operator name is mandatory for Combat products for both new and existing IMG clients.

  1. Before Store licence activation, check the IMGA repository for an existing operator name.
  2. Reuse an existing operator name for LMT activation.
  3. If none exists, create a new operator ID through the standard process.
  4. Enter the confirmed or created operator name in Store’s imgaOperator field during LMT activation.

IMGA TEAM · IF UFC STREAMING IS REQUESTED

Request UFC streaming

  1. Confirm that the IMGA operator name is available.
  2. Contact the IMGA team (Faisal Hussain) in #bets-img-operator-setup.
  3. Request streaming activation with the operator name, UFC league, requested regions, and licensing period.
  4. Ask whether each requested region is available and, if required, whether it can be enabled.
  5. For a new client, provide the client POC’s name and email address.
  6. Ask IMGA to share the operator ID and streaming token via Keeper when setup is complete.

Request example

“Please activate streaming for [operator name]. Please confirm if the region is available; if not, can it be enabled? The stream should cover UFC from [start] to [end]. Once ready, please share the operator ID and token via Keeper.”

BET INTEGRATION · STREAMING ONLY

Create and share the Keeper link

  1. Wait for IMGA to provide the operator ID and streaming token.
  2. Generate a one-time Keeper link containing the credentials.
  3. Configure the link to remain active for one week.
  4. Send it separately to the client, preferably by email.

Single-use warning

Do not open the link yourself or allow anyone other than the intended recipient to open it first. Credentials are available only to the first person who opens the link.

BET INTEGRATION TEAM

Send the client integration handover

  1. When all applicable setup is complete, email the client POC confirmed by Sales.
  2. Put relevant Sales representatives in CC.
  3. Confirm the client can proceed with integration and provide the Store ClientID.
  4. If UFC streaming is enabled, share the Keeper credentials link separately.
  5. Share the referenced client email-communication template.
  6. Share Events API information for available streaming content, including events and coverage.
  7. Share geo-restriction documentation so the client can identify streamable events and configure geofencing.

IMGA / BET INTEGRATION

Route integration and streaming issues

Forward every client integration or streaming issue to #bets-img-operator-setup.

Use the channel to coordinate follow-up with the IMGA team.
