1 · SALES REPS

Salesforce account info

New client

OPEN A NEW ACCOUNT via Sales Force:

CREATE A NEW OPPORTUNITY with a Quote where respective product is chosen.

Existing client

CREATE A NEW OPPORTUNITY with a Quote where respective product is chosen.

or

AMEND OPPORTUNITY with a Quote where respective product is chosen.

2 · SALES REPS

Service administration

REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Define the type of request by ticking the right box (Service Request, Service Prolongation etc.).

Define a function (Pre-sales Trial, Post Sales Integration) and choose the products you want to activate.

Enter Service Start Date.

Also Provide :

  • IPs / Domains that should be whitelisted in respective box (mandatory);
  • Store ID if available (for existing BET clients on Widget type solutions) in comments box.

Provide Bookmaker ID field is not obligatory for Widget type solutions.

Finish the process, by clicking on Finish button.

JIRA TICKET will be automatically created for the BETI team, and you would be able to see it by clicking on the respective link.

3 · BETI TEAM

Client setup

Once Jira is created BETI team will create a STORE ACCOUNT if needed, or just create a new ORDER, activate selected products (trial or production license) and update Bookmaker ID if needed.

In case additional info is needed BETI team will request it via Jira ticket.

BETI team will update the Jira by adding INTEGRATION INTRUCTIONS PDF file* as well as Store Link so you would be able to download this file if needed.

SOX approval:

If all products are licensed according to the request:

  1. Mark the SOX checks boxes shown at the right hand banner of Jira ticket;
  2. Assign the ticket back to BET-Integrations user;
  3. Close the ticket.

* INTEGRATION INTRUCTIONS PDF file consist of all integration details (Product list/sport list, whitelisted domains, Client ID, integration documentation and link to video how to setup BET products).

4 · BETI INTEGRATIONS

Finalization

INTEGRATION INTRUCTIONS PDF file needs to be sent to the client to finalize integration process.

‼️Trial phase lasts for 45 days and only one prolongation is possible (28 days).
