1 · SALES REPS

Salesforce account info

New client

OPEN A NEW ACCOUNT via Sales Force:

CREATE A NEW OPPORTUNITY with a Quote where respective product is chosen.

Existing client

CREATE A NEW OPPORTUNITY with a Quote where respective product is chosen.

or

AMAND OPPORTUNITY with a Quote where respective product is chosen.

2 · SALES REPS

Service administration

REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Define the type of request by ticking the right box (Service Request, Service Prolongation etc.), and a function (Pre-sales Trial, Post Sales Integration). Choose the products you want to activate.

Also Provide :

  • IPs / Domains that should be whitelisted in respective box (mandatory);
  • Bookmaker ID or request a new one by ticking the box Create bookmaker ID.

Finish the process, by clicking on Finish button.

JIRA TICKET for StatsHub will be automatically created for the Client Setup team, and you would be able to see it by clicking on the respective link.

OPEN created Jira Ticket and ADD Setup document for StatsHub.

3 · CLIENT SETUP TEAM

Technical activation

Client Setup team will add StatsHub technical activation in ISA (details), and make adjustments in HSA if needed (details).

When the bookmaker is set, CS assigns the Jira ticket to BET Integrations.

3 · BETI TEAM

Prepare staging link

BETI team will prepare StatsHub Staging link and add it to Jira ticket.

3 · ADDITIONAL

Client confirmation

SHARE Staging link with a client for final confirmation.

Communicate all possible changes via JIRA TICKET.

When CLIENT CONFIRMS, INFORM the BETI team via respective JIRA TICKET.

3 · BETI TEAM

Prepare production link

BETI team will prepare PRODUCTION LINK which will be added to Jira ticket.

3 · ADDITIONAL

SOX approval

SOX approval (edit button → check box). Click UPDATE and reassign ticket back to Client Setup Team.

Add comment that all is good.

3 · BETI TEAM

Close ticket

When BETI Team gets your update/check, they will close the ticket.

4 · ADDITIONAL

Share Production Link

SHARE Production Link with a client for final integration.

4 · ADDITIONAL

Trial and setup guidance

In general, we DO NOT recommend activating a TRIAL for StatsHub.

Production link will remain the same for both trial and active subscription.

‼ Trial phase lasts for 45 days and only one prolongation is possible (28 days).

Setup document can be found on product Confluence page located on the right sidebar (lower part): StatsHub Setup Document.
