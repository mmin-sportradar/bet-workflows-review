2 · SALES REPS · JIRA SERVICE REQUEST CREATION

Jira Service Request Creation

Request the service

Request the service via the “Service Administration” button.

Define a function (Pre-Sales Trial, Post-Sales Integration).

Mandatory request details

  • IPs / Domains that should be whitelisted
  • Store ID if available (for existing BET clients on Widget type solutions)
  • Active Bookmaker ID

Automatic Jira ticket

A Jira ticket will be automatically created for the Bet Integration team. In case mandatory requests are not specified, the Bet Integration team will request them via Jira ticket comment.

Trial phase lasts for 90 days and only one prolongation is possible.

3 · BETI TEAM · INTERNAL INITIATIVE / EPIC

Internal Initiative / Epic Jira Ticket Creation

When a Service Request ticket is received, BETI team needs to follow the General Adapter Setup flow with Jira automation triggers of product-specific components. Detailed instructions can be found here.

4 · ADDITIONAL · COMMUNICATION CHANNEL CREATION

Communication Channel Creation

Shared channel

BETI team will establish a shared Slack channel, including the Sales director and Sales support specialist for the initial setup phase.

Either Sales director or Sales support specialist will invite members from the client’s team to kick-off the setup process.

Both the SR technical team and the client’s technical team will be included in the channel to monitor the progress of technical development.

Requests to add external people to Slack channels can be made here. For clients using MS Teams, see the instructions here.

Bet Insights specific

At the technical meetup with the client, the contents of the API need to be discussed. Client needs to specify which packages from Bet Insights they want to use: Bet Insights Soccer, Tournament widget, or both.
