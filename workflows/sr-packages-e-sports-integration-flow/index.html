LMT eSports (GRID)

Quick integration flow

Responsibilities:
Package scope: enable LMT eSports for Counter-Strike, League of Legends, Dota 2 and Valorant. No Premium or Compact version is available.
SPORTRADAR
3 September 2026

BET INTEGRATION TEAM

Enable the eSports package in Store

  1. Confirm the Salesforce request is for the LMT eSports Package.
  2. Enable LMT through the standard Store integration flow for all four supported titles.

Supported titles

  • Counter-Strike
  • League of Legends (LoL)
  • Dota 2
  • Valorant

Package limitation

No Premium or Compact version is available.

GRID TEAM

Whitelist client domains in GRID

  1. After enabling the widget in Store, notify the GRID team in #shared-sportradar-widgets.
  2. Request whitelisting for the required client domain or domains.
  3. Once GRID confirms completion, notify Sales that the widget is enabled.

BET INTEGRATION TEAM

Check the required language

GRID currently supports the following languages:

  • English (en)
  • Polish (pl)
  • Swedish (sv)
  • Greek (el)
  • Korean (ko)

Fallback

If the client’s requested language is not supported, use English as the default fallback.

GRID TEAM

Request a custom translation

If the client requires a language that is unavailable, contact the GRID team in #shared-sportradar-widgets.

Request integration-level support for a custom translation.
