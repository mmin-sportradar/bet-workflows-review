Salesforce Account Info

New client

OPEN A NEW ACCOUNT via Sales Force:

CREATE A NEW OPPORTUNITY with a Quote where respective package (under BET New) is chosen.

Existing client

CREATE A NEW OPPORTUNITY with a Quote where respective package (under BET New) is chosen.

or

AMAND OPPORTUNITY with Quote where respective package (under BET New) is chosen.

2 · SALES REPS

Selection

Product selection

Products of respectively selected package are predefined. Details.

Sport selection

  1. Select number of sports (number of units) and click “save”;
  2. In “Edit Quote” section, select the package and click “Reconfigure line(s)” to specify them.

Amount split

You only need to define the price of the package. Distribution among the products is set automatically. Details.

3 · SALES REPS

Service Administration

REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Define the type of request by ticking the right box (Service Request, Service Prolongation etc.).

Define a function (Pre-sales Trial, Post Sales Integration) and choose the products you want to activate.

Enter Service Start Date.

Also Provide :

  • IPs / Domains that should be whitelisted in respective box (mandatory);
  • Store ID if available (for existing BET clients on Widget type solutions) in comments box.

Provide Bookmaker ID field is not obligatory for Widget type solutions.

Finish the process, by clicking on Finish button.

JIRA TICKET will be automatically created for the Customer Care team, and you would be able to see it by clicking on the respective link.

SOX approval

If all products are licensed according to the request, go to EDIT button (upper left) and mark the boxes shown at the end. Click UPDATE and reassign ticket back to Customer Care team. Add comment that all is set properly.

When Customer Care team gets your update/check, they will close the ticket.

4 · BETI TEAM

Setup of the Client

Once Jira is created Customer Care team will create a STORE ACCOUNT if needed, or just create a new ORDER, activate selected products (trial or production license) and update Bookmaker ID if needed.

In case additional info is needed Customer Care team will request it via Jira ticket.

Customer Care team will update the Jira by adding INTEGRATION INTRUCTIONS PDF file* as well as Store Link so you would be able to download this file if needed.

Integration instructions

* INTEGRATION INSTRUCTIONS PDF file consist of all integration details (Product list/sport list, whitelisted domains, Client ID, integration documentation and link to video how to setup BET products.

5 · SALES REPS

Finalization

INTEGRATION INTRUCTIONS PDF file needs to be sent to the client to finalize integration process.

Package sport-selection flexibility

Flexibility of sport selection across different products within same package is possible.

From now on there is only one product (single product code per product), with sports defined as attributes (previously, each product and sport combination had its own product code).
