LMT Golf BET Integration

New-client setup for Premium Golf Service Essential and Advanced

Responsibilities:
Package scope: Essential activates LMT. Advanced activates LMT + LMT Premium + streaming with the IMGA team.
SPORTRADAR
3 September 2026

BET INTEGRATION TEAM

Identify the Salesforce package

  1. Check whether Salesforce requested Premium Golf Service Essential or Premium Golf Service Advanced.
  2. Both requests are cross-unit bundles. Salesforce requests go to the CS team first; CS later clones tickets and assigns LMT-integration work to BETI.
  3. Apply the corresponding activation scope.

Essential

Activate LMT.

Advanced

Activate LMT + LMT Premium + streaming with the IMGA team.

SALES / BET INTEGRATION

Confirm client details

  1. Add a comment to the relevant Jira ticket and contact the Sales representative.
  2. Ask Sales to confirm the client’s integration point of contact (POC).
  3. For Advanced, also ask Sales to confirm the required streaming regions.
  4. Do not proceed with client-facing setup until these details are available.

BET INTEGRATION TEAM

Prepare the IMGA operator name

The IMGA operator name is mandatory for both Essential and Advanced.

  1. Check the IMGA repository for an existing client IMGA operator name.
  2. If it exists, reuse it for LMT activation.
  3. If it does not exist, create a new operator ID using the standard operator-creation process.
  4. Enter the confirmed operator name in Store’s imgaOperator field during LMT activation.

IMGA TEAM · ADVANCED ONLY

Request streaming credentials

  1. Confirm the client is on Premium Golf Service Advanced and that the IMGA operator name is ready.
  2. Contact the IMGA team (Faisal Hussain) in #bets-img-operator-setup.
  3. Request streaming activation with the IMGA operator name, leagues, required region, and licensing period.
  4. Ask whether the region is already available; if not, ask whether it can be enabled.
  5. Request the operator ID and streaming token via Keeper once ready.
  6. For new clients, provide the client POC’s name and email address.

Request example

“Please activate streaming for [operator name]. Please confirm if the region is available; if not, can it be enabled? The stream should cover [league] from [start] to [end]. Once ready, please share the operator ID and token via Keeper.”

BET INTEGRATION TEAM · ADVANCED ONLY

Create the Keeper credentials link

  1. Wait until IMGA provides the operator ID and streaming token.
  2. Create a one-time Keeper link containing those credentials.
  3. Set the link to remain active for one week.
  4. Share it with the client separately, preferably by email.

Single-use warning

The link must not be opened by anyone else: credentials are available only to the first person who opens it.

BET INTEGRATION TEAM

Send the client integration handover

  1. Email the client POC confirmed by Sales and put relevant Sales representatives in CC.
  2. Confirm the client can proceed with integration and provide the Store Client ID.
  3. For Advanced, include the separately shared Keeper link with streaming credentials.
  4. Share the referenced email-communication template.
  5. Share AsP API documentation for available streaming content, including events and coverage.
  6. Include geo-restriction rules so the client can identify streamable events and configure geofencing.

IMGA / BET INTEGRATION

Route follow-up issues

Direct all client integration or streaming issues to #bets-img-operator-setup.

Use the channel for follow-up with the IMGA team whenever streaming is involved.
