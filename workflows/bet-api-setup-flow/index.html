Production packages increasement Reference the specific upsell process when increasing calls on Production packages.

1 · SALES REPS

Developer Portal

Send client Developer Portal where they can check API documentation, FAQs and REGISTER*.

*Direct clients to registration instructions

!!obligatory process, for both Trials and Production).

After registration, client would be able to SELF ISSUE A TRIAL KEY via Developer Portal.

For REGULAR TRIAL activated via Developer portal, client will get 1000 calls per month for each API:

  • There is no data limitation on trial key, only no. calls is limited;
  • Trial will last for 90 days.

!!Client should never use the trial keys in production environment.

2 · SALES REPS

Salesforce Account Info

Regular Trial

If your client self-issued a TRIAL via Dev portal for REGULAR TRIAL purposes, you DO NOT NEED to trigger any setup process via SF. Having Oppty is also optional but recommended.

Qualified Trial

In case your client wants to test more calls than he gets with self-issuing via Dev Portal you need to involve Sales Force process to request Qualified trial.

CREATE A NEW OPPORTUNITY with a Quote where API product is chosen (you need to select each sport with respective package) or AMAND OPPORTUNITY with a Quote where API product is chosen (you need to select each sport with respective package).

Quote Product Selection level-select product line API Betting (new API line for betting sales) and under respective sport choose the Real-Time Package (Qualified trial will work only on a basis of this package).

!! Trial with increased no. of calls, can last max 90 days and it is responsibility of Sales Reps to inform SDSUP that this special trial has expired.

Production packages

On Quote level, select API Betting (new API line for betting sales) and on next level select agreed package.

!! Production packages can be requested and will be issued ONLY when Contract is signed, or Exceptional Invoicing activated.

3 · SALES REPS

Service Administration

When Quote is ready, REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Qualified Trial

Request Pre-Sales Trial.

Production keys request

Request Post-Sales Integration.

Console ID - Mandatory

No matter if a Pre-sales Trial or Post-Sales Integration is requested, Sales Reps need to enter a client’s Console ID on “Service Administration” level, so SDSUP team can identify the client on Dev portal.

If Console ID for respective client was requested in the past, tick “Assign Console ID?” box and choose username in next stage.

If Console ID is entered for the first time on the SF, tick the box “Create New Console ID” and then enter the ID in the “New Console ID” box.

!! Client needs to provide his Console ID to the Sales Rep, as he created it when registered on Developer portal.

4 · BETI TEAM

Ticket validation

JIRA TICKET will be automatically created for the BETI team first - they need to check all ticket details before passing it to SDSUP team for actual key activation.

5 · SDSUP TEAM

Client setup

SDSUP team will find the client via Console ID on Developer portal.

In case additional info is needed, SDSUP team will request it via Jira ticket.

Qualified Trial

SDSUP team will update the Jira by adding info that no. of calls on trail has been increased, so client can continue testing by using the same trial keys he got from Developer portal when self-issued trial keys.

!! Trial with increased no.ofcalls,canlast only 30 days.

Production packages

When PRODUCTION PACKAGES are ready to be added to client’s Dev Portal Account, SDSUP team will assign Jira ticket back to Sales Rep and change ticket status to “QA”.

6 · SALES REPS

Production QA

Sales Rep needs to check if everything is set according the deal.

SOX approval:

If Production Packages are set for requested type of key (sport) and type of plan (package), go to EDIT button (Jira’s upper left) andmarktheboxes shown at the end. Click UPDATE and reassign ticket back to Support Team.

7 · SDSUP TEAM

Key activation

When Support Team gets update/QA from Sales Reps, they add Production packages to client’s Dev Portal Account and close the ticket.

8 · SALES REPS

Finalization

Sales Rep may INFORM their client that Production packages have been sent to their Dev Portal account.

ADDITIONAL · GOOD TO KNOW AND DO

Production packages increasement

Increasing no. of calls on Production packages is available only in case your client is using Real-Time package. For all other packages you just need to move to next (bigger) package (e.g. Standard → Premium / Real-Time; Premium → Real time).

  1. Create New Amend Oppty under respective Account and Quote.
  2. On Quote Product Selection level select product line API Betting (new API line for betting sales) and under respective sport choose the option Additional calls.
  3. !! Request Invoice activation as Increasement on Production packages needs to be an upsell and result with Contract amend phase initiated.

When you request Invoice Activation for the API make sure you request also Service Administration.
