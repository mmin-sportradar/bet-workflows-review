1 · ADDITIONAL

Product offer

LMT Premium is premium product that can be offered ONLY to Strategic clients and Top Tier (Tier 1 and Tier 2) VBP clients. For existing LMT clients, this is a drop-in replacement with no additional integration needed. LMT Premium implies faster data for LMT and LMT Compact.

Trial policy

No pre-sale trial available for this product. For demonstrational purposes, Demo link can be shared. To access the link, please reach out to Uroš Prah or Blaž Bezek.

Strategic accounts

  • LMT Premium is sold as a standalone product;
  • Clients can decide if they want to take all sports in Premium.

Tier 1 VBP clients

  • LMT Premium is a part of Essential and Ultimate Package;
  • Clients can only change existing LMT with LMT Premium for selected / current sports (it can only be a 100% replacement of LMT).

2 · SALES REPS

Salesforce Account Info

CREATE A NEW OPPORTUNITY with a Quote where respective product/bundle is chosen.

or

AMAND OPPORTUNITY with a Quote where respective product /bundle is chosen.

LMT Premium is a single subscription for two widgets (LMT and LMT Compact).

When LMT Premium is sold as a part of the bundle, don’t forget to amend the bundle on the contract (replace LMT with LMT Premium and remove LMT Compact).

LMT Premium encompasses faster data for LMT and LMT Compact. One product in SF (LMT Premium) implies two widgets (LMT and LMT Compact) and three Store licences (LMT, LMT Compact, LMT Premium).

3 · SALES REPS

Service Administration

REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Define the type of request by ticking the right box (Service Request, Service Prolongation etc.).

Define a function (Pre-sales Trial – only for new LMT clients; Post Sales Integration) and choose the product you want to activate.

Enter Service Start Date.

Also Provide :

  • IPs / Domains that should be whitelisted in respective box (mandatory);
  • Store ID if available (for existing BET clients on Widget type solutions) in comments box.

Provide Bookmaker ID field is not obligatory for Widget type solutions.

Finish the process, by clicking on Finish button.

JIRA TICKET will be automatically created for the Customer Care team, and you would be able to see it by clicking on the respective link.

4 · BETI INTEGRATIONS

Client setup

Once Jira is created Customer Care team will create a STORE ACCOUNT if needed, or just create a new ORDER, activate selected products (trial or production license) and update Bookmaker ID if needed.

In case additional info is needed Customer Care team will request it via Jira ticket.

LMT Premium encompasses faster data for LMT and LMT Compact. One product in SF (LMT Premium) implies two widgets (LMT and LMT Compact) and three Store licences (LMT, LMT Compact, LMT Premium).

SOX approval

If all products are licensed according to the request, go to EDIT button (upper left) and mark the boxes shown at the end. Click UPDATE and reassign ticket back to Customer Care team.

Add comment that all is set properly.

New LMT clients

For new LMT clients, Customer Care team will update the Jira by adding INTEGRATION INTRUCTIONS PDF file as well as Store Link so you would be able to download this file if needed.

When Customer Care team gets your update/check, they will close the ticket.

5 · SALES REPS

Finalization

INTEGRATION INTRUCTIONS PDF file needs to be sent to the new LMT clients to finalize integration process.

Existing LMT clients just need to be informed that faster data stream has been enabled on already integrated LMT and LMT Compact.
