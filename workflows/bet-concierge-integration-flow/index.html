Optional additional steps for deeper integration

Full and premium integration

1 · INITIAL SETUP

Initial Setup

Widget licensing

  • Client setup licenses Bet Concierge Widget in Store;
  • Sends the Integration Instructions PDF file to the client.

Definitions

  • Client sends a list of domains to be whitelisted;
  • Client defines prompt limitations:
    • Monthly / weekly prompt limit (total);
    • Number of prompts per end user (e.g. 100 prompts daily);
    • Number of prompts per user group (e.g. 100 prompts daily for regular users, unlimited prompts for VIP users);
    • Concurred (number of prompts in selected time frame. Default set to max 60 prompts in 60 seconds).

2 · CLIENT · 1–2 DAYS

Authentication

Public / private key

Client needs to create a pair of RSA keys – Public and Private:

  • Public key needs to be sent to Sportradar for setting up the product;
  • Private key is utilized on the client’s side to generate JWT token.

3 · SPORTRADAR · 1 DAY

Configuration

Authentication and configuration

  • BET Integration team applies the provided Public RSA key;
  • BET Integration team configures the defined prompt limits.

4 · CLIENT · 1–2 DAYS

Integration

Widget integration and styling

  • Client integrates widget as an pop-up element;
  • Applies theming;
  • Configures other parameters.

5 · SPORTRADAR · FULL INTEGRATION · 1–5 DAYS

Adapter

Sportradar prepares a data adapter that enables communication between Bet Concierge and the client’s API.

6 · CLIENT · FULL INTEGRATION

ID Mapping

Mapping of client match and tournament IDs to Sportradar IDs.

7 · CLIENT · PREMIUM INTEGRATION · 5 DAYS

Custom Bet

Custom Bet integration for combo markets.
