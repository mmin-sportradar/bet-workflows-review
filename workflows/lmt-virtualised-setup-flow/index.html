2 · SALES REPS

Service Administration

REQUEST THE SERVICE via “Service Administration” button on the Opportunity level.

Define the type of request by ticking the right box (Service Request, Service Prolongation etc.).

Define a function (Pre-sales Trial, Post Sales Integration) and choose the products you want to activate.

Enter Service Start Date.

Also Provide :

  • IPs / Domains that should be whitelisted in respective box (mandatory);
  • Store ID if available (for existing BET clients on Widget type solutions) in comments box.

Provide Bookmaker ID field is not obligatory for Widget type solutions.

Finish the process, by clicking on Finish button.

JIRA TICKET will be automatically created for the Customer Care team, and you would be able to see it by clicking on the respective link.

3 · BETI INTEGRATIONS

Client Setup

Once Jira is created Customer Care team needs to check whether the client really has LCO rights for respective tournament on this file (search under corresponding CRM ID). If not, please contact Philipp Hampl (AV) and Blaž Bezek (BET).

Customer Care team will create a STORE ACCOUNT if needed, or just create a new ORDER, activate selected product (trial or production license) and update Bookmaker ID if needed.

In case additional info is needed Customer Care team will request it via Jira ticket.

Customer Care team will update the Jira by adding INTEGRATION INSTRUCTIONS PDF file as well as Store Link so you would be able to download this file if needed.

SOX approval

If the product is licensed according to the request, go to EDIT button (upper left) and mark the boxes shown at the end. Click UPDATE and reassign ticket back to Customer Care team. Add a comment that all is set properly.

When Customer Care team gets your update/check, they will close the ticket.

Integration instructions

* INTEGRATION INSTRUCTIONS PDF file consist of all integration details (Product list/sport list, whitelisted domains, Client ID, integration documentation and link to video how to setup BET products).

ADDITIONAL · CRITICAL DETAILS

Product conditions and availability

Important to know

In SalesForce, LMT Virtualised’s and LCO’s subscriptions end dates must be the same. In order to have a LMT Virtualised product, client needs both LMT and LCO, for the respective sports.

If the client doesn’t have or doesn’t want to have LCO and wants LMT Virtualised, please contact AV Sales, AV BDM or BET BDM.

Country-specific conditions

LMT Virtualised NBA can be sold only in the Restricted/Light version in the following countries:

USA

LMT Virtualised UEFA can be sold without LCO.

LMT Virtualised Soccer Bundesliga DFL can be sold without LCO in the following countries:

Germany · Austria · Switzerland · Liechtenstein · Luxembourg · USA

Product versions

LMT Virtualised Product versions: Full and Restricted/Light.

Full contains both views (3D and 2D top-down views).

Restricted/Light contains only 2D top-down view.
