2 · SALES REPS

Salesforce Account Info

CREATE A NEW OPPORTUNITY with a Quote where respective API product is chosen (API Utility and/or API Mapping) or AMEND OPPORTUNITY with a Quote where product is chosen.

API Mapping product activation will continue ONLY when Contract is signed, or Exceptional Invoicing activated.

3 · SALES REPS

Service Administration

When Quote is ready, REQUEST THE SERVICE via “Service Administration” button on the opportunity level.

OBLIGATORY - Sales Reps need to:

  1. Enter client’s Console ID on “Service administration” level, so setup teams can identify the client on Dev portal (mandatory for both BET API Utility and BET API Mapping);
  2. Enter client’s Bookmaker ID (mandatory only for BET Mapping).

If Console ID for the respective client was requested in the past, tick “Assign Console ID?” box and choose username in next stage. If Console ID is entered for the first time in SF, tick the box “Create New Console ID” and then enter the ID in the “New Console ID” box.

4 · SDSUP TEAM

Client Setup - SDSUP

Unlike the regular API process, clients do not self issue a trial key via Developer Portal. Client only registers via Console and waits for products to be configured and sent to their Dev Portal account.

SF request triggers automatic SDSUP Jira ticket.

When SDSUP receives BET API Mapping or BET API Utility request, they enable the packages on Developers portal. In case additional info is needed, SDSUP team will request it via comment on Jira ticket.

SDSUP informs BETI team about package activation: assigns the ticket to BET-Integrations Jira user and adds a link from Marketplace to the account where packages were enabled (so that BETI can obtain the API key).

5 · BETI TEAM

Client Setup - BETI

BET API Utility

BETI team does the sport configuration (all sports) in the Fishnet Client Configuration API and attaches Technical documentation to the ticket.

BET API Mapping

BETI team does the sport configuration (all sports), adds the Bookmaker ID in the Fishnet Client Configuration API and attaches Technical documentation to the ticket. Sales follows up with the Client and Support/Crawler team for the mapping process.

QA and ticket closure

BETI informs the Sales via respective Jira Ticket, assigns the ticket to Sales Rep and changes ticket status to QA.

Sales Rep needs to check if everything is set according to the deal and do the SOX approval.

When BETI team gets update / QA from Sales Reps, they close the ticket.

6 · SALES REPS

Finalization

Sales Rep may inform their client that Products have been sent to their Dev Portal account. They also provide a link to the Technical Documentation for API Utility and/or API Mapping.

ADDITIONAL · PRODUCTION PACKAGES INCREASEMENT

Product context and call limit

These APIs are tailored for betting purposes and provide information on Tournament IDs for the entire season. BET API Utility: the client manages the mapping and it is offered free of charge. BET API Mapping: requires a monthly subscription and includes the mapping service.

The call limit is set to 100,000 calls on a rolling 30-day basis, and if the client exceeds this limit, they should be directed to use the Sports API instead.
